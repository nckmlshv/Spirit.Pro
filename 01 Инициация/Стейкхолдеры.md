## Стейкхолдеры

| Роль | Интерес в проекте | Влияние |
|------|-------------------|---------|
| **Администраторы (АК)** | Меньше ручной перепроверки, больше времени на клиента и продажи |Умеренное |
| **Старшие администраторы (СТАК)** | Меньше эскалаций по ошибкам подчинённых, контроль процессов клуба | Умеренное|
| **Управляющие (УК)** | Достоверная аналитика по клубу без ручной сверки, контроль стоп-листа |Высокое |
| **Руководители секторов (РС)** | Единая картина по сети клубов для принятия более эффективных управленческих решений |Высокое |
| **Бизнес-директор** | Стратегическая видимость по сети в целом, обоснованность инвестиций в развитие |Высокое |
| **Специалисты отдела аналитики** | Достоверные и структурированные данные для более точной обработки |Умеренное |
| **Специалисты отдела маркетинга** | _Требует уточнения_ |Не определено |
| **Тренеры** | Удобный личный кабинет с записями клиентов и собственным графиком работы, планирование дежурств и замен |Умеренное |
| **Старшие тренеры** | Формирование графика работы тренерского состава, аналитика и отчётность | Умеренное|
| **Секторальные координаторы тренажёрного зала (СКТЗ)** | Аналитика и координация работы тренеров по нескольким клубам сектора | Высокое|
