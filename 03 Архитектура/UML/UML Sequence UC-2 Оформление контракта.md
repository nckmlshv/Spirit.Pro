<summary>Исходный код диаграммы</summary>

```plantuml
@startuml
title UC-2. Оформление контракта
@startuml
autonumber
skinparam responseMessageBelowArrow true

actor "Админимтратор" as AK
participant "Staff Frontend" as FE
participant "API Gateway" as GW
participant "Staff BFF" as BFF
participant "IAM Service" as IAM
participant "Client Service" as CL
participant "Membership Service" as MB
participant "Loyalty Service" as LOY
participant "Billing Service" as BIL
participant "Платёжный шлюз" as PAY
participant "Access Control" as AC
participant "Document Service" as DOC
participant "Notification Service" as NOT

AK -> FE : Оформить абонемент
FE -> GW : POST /contracts
GW -> IAM : Проверка токена и скоупа
IAM --> GW : Роль: АК, Спирит Гагаринский
GW -> BFF : Запрос разрешён

BFF -> CL : Данные клиента
CL --> BFF : ПЧК, 32 года, email заполнен

BFF -> MB : Проверить допустимость тарифа
MB -> MB : Валидация бизнес-правил:\nвозраст, статус, стоп-лист

alt Правила не выполнены
    MB --> AK : Отказ с указанием причины
end

opt Указан промокод
    BFF -> LOY : Проверить промокод
    LOY --> BFF : Скидка 15%
end

BFF -> MB : Создать контракт (draft)
MB --> BFF : Контракт №4821, к оплате 4165 ₽

BFF -> BIL : Провести оплату (idempotency-key)
BIL -> PAY : Списание
PAY --> BIL : Успешно, чек

alt Оплата отклонена
    BIL --> MB : Отмена
    MB -> MB : Компенсация —\nконтракт аннулирован
    MB --> AK : Оплата не прошла
else Оплата подтверждена
    BIL --> MB : Оплата подтверждена
    MB -> MB : Контракт активен,\nклиент → ЧК

    par
        MB -> AC : Активировать браслет
    else
        MB -> LOY : Начислить бонусы
    else
        MB -> DOC : Сформировать договор
    else
        MB -> NOT : Уведомить клиента
    end

    AC --> BFF : Доступ открыт
    BFF --> FE : Контракт оформлен
    FE --> AK : Готово, браслет активен
end
@enduml@enduml
```
