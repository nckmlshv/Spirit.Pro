# POST /contracts → Membership Service

Спецификация обработки POST-запроса в сервис абонементов на создание контракта.

## Назначение

Оформление нового контракта для клиента. Контракт создаётся в статусе ожидания оплаты, клиенту формируется платёжная ссылка со сроком действия 24 часа. Метод обслуживает как оформление первого контракта, так и продление при наличии действующего — в последнем случае дата начала вычисляется системой автоматически.

## Заголовки запроса

| Заголовок | Обязательный | Описание |
|---|---|---|
| Authorization | Да | Bearer-токен формата JWT. Содержит идентификатор субъекта, роль и область видимости данных |
| X-Request-Id | Да | UUID, сквозной идентификатор запроса для сопоставления записей в журналах |
| Idempotency-Key | Да | UUID, ключ идемпотентности операции |
| Content-Type | Да | application/json |

## Входные данные

| Поле | Тип данных | Обязательное | Ограничения / Описание |
|---|---|---|---|
| clientId | string | Да | UUID, идентификатор клиента |
| tariffId | string | Да | UUID, идентификатор выбранного тарифа |
| clubId | string | Да | UUID, идентификатор клуба оформления |
| operationalDayId | string | Да | UUID, идентификатор открытой операционной смены |
| deliveryChannel | string | Да | Способ доставки ссылки на оплату: SMS, PUSH, EMAIL, PRINTABLE_QR |
| workstationId | string | Нет | UUID рабочего места, с которого выполняется оформление |

## Выходные данные

| Поле | Тип данных | Обязательное | Описание |
|---|---|---|---|
| contractId | string | Да | UUID созданного контракта |
| status | string | Да | Статус контракта, PENDING_PAYMENT |
| previousContractId | string | Нет | UUID действующего контракта клиента при оформлении продления |
| startDate | string | Да | Дата начала действия контракта, формат ISO 8601 |
| endDate | string | Да | Дата окончания действия контракта, формат ISO 8601 |
| amount | number | Да | Стоимость контракта к оплате |
| paymentUrl | string | Да | Ссылка на страницу оплаты |
| paymentExpiresAt | string | Да | Дата и время истечения срока действия ссылки, формат ISO 8601 |

## Алгоритм работы сервиса абонементов

1. Проверить идемпотентность операции по Idempotency-Key
    - Операция уже обработана → Вернуть результат предыдущей операции
2. Запросить данные клиента в сервисе клиентов и тариф по tariffId
3. Проверить бизнес-правила оформления:
    - У клиента есть непогашенная задолженность → 409
    - У клиента уже оформлен следующий контракт → 409
    - У клиента есть контракт в статусе ожидания оплаты → 409
    - Возраст клиента не соответствует условиям тарифа → 409
4. Рассчитать параметры контракта:
    - Дата начала: при наличии действующего контракта — следующий день после его окончания, иначе определяется по правилу активации
    - Дата окончания и стоимость — на основании условий тарифа
5. Создать контракт в статусе PENDING_PAYMENT, при наличии действующего установить связь с ним
6. Направить запрос в сервис биллинга на создание платежа со сроком действия ссылки 24 часа
7. Направить ссылку клиенту в соответствии с deliveryChannel:
    - SMS, PUSH, EMAIL → сервис уведомлений
    - QR_PRINT → сервис документов
8. Вернуть ответ 201 Created

## Ошибки

### Формат ошибки

| Поле | Тип данных | Описание |
|---|---|---|
| code | string | Код ошибки |
| message | string | Описание ошибки |
| details | object | Дополнительные данные об ошибке |
| requestId | string | Идентификатор запроса для трассировки |

### Пример ошибки

    HTTP/1.1 409 Conflict
    X-Request-Id: 7c2f9e14-6b83-4d51-a9e7-2f5c8b1d3a60

    {
      "code": "PENDING_CONTRACT_EXISTS",
      "message": "У клиента есть незавершённая операция оформления контракта",
      "details": {
        "clientId": "3f2a91c4-8d17-4e6b-9c3a-1b7f5e2d8a04",
        "contractId": "d6c8e402-9b13-4a7f-8e25-3d1c6b8a5f74",
        "paymentExpiresAt": "2026-08-29T14:35:00+03:00"
      },
      "requestId": "7c2f9e14-6b83-4d51-a9e7-2f5c8b1d3a60"
    }

## Возможные ошибки

| Код | Описание |
|---|---|
| 400 | Отсутствуют обязательные заголовки запроса |
| 401 | Токен недействителен или срок его действия истёк |
| 403 | Роль не имеет права на оформление контрактов |
| 404 | Клиент или тариф не найдены |
| 409 | У клиента есть непогашенная задолженность |
| 409 | У клиента уже оформлен следующий контракт |
| 409 | Тариф недоступен клиенту по возрасту |
| 422 | Ошибка валидации входных данных |
